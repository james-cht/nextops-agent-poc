# ADR-0011: Unified Runtime Dify credentials via SRE admin

Admin “AI Agents” fields were `effect: demo` (browser localStorage) while OPSGPT and Tool Endpoint auth actually read process env (`DIFY_BASE_URL`, `DIFY_API_KEY`, `NEXTOPS_DIFY_TOKEN`), with a second misleading pair `PUBLIC_DEFAULT_DIFY_*`. We unify on those three env names as the only credential vocabulary: deployment env is bootstrap; Cluster Operators may override them as Runtime Settings (server `.data` + in-memory, immediate apply, single-instance only), with restore-to-env that clears the override. Saving or restoring any Runtime Setting (including MySQL proxy) requires admin-password step-up and an explicit “takes effect immediately” notice; Dify Chat Credentials and Tool Endpoint Token additionally require format validation and a live probe before persist (Chat: reachable `{base}/chat-messages`; Tool token: Bearer self-check on a protected Tool Endpoint). Secrets are masked in Admin reads; empty secret fields mean “leave unchanged.” A Config Audit Log (server append-only + structured stderr; no plaintext secrets) records attempts/outcomes and is browsable at a dedicated `/admin/audit` view. The Image Allowlist follows the *effective* Chat base URL hostname. `PUBLIC_DEFAULT_DIFY_*` are removed so Admin cannot imply a second source of truth.

**Considered options:** keep demo localStorage (operator confusion, caused `fetch failed` when env stayed wrong); write `.env` from Admin (restart required, host permissions); DB/Redis for multi-replica (out of scope—deployments are single-instance); merge Chat key and Tool Endpoint Token into one secret (wrong trust directions); allowlist frozen to bootstrap env only (images break after URL override).

**Consequences:** `/api/ai/query` and Tool Endpoint auth must resolve *effective* credentials, not raw env alone; Dify Integrators still configure Chatflow Bearer to match the effective Tool Endpoint Token; bad overrides that pass probes can still be wrong for business logic—audit + restore-to-env are the escape hatches; multi-replica shared config remains unsupported until a later ADR.
