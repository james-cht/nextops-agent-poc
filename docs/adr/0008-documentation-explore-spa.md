# Documentation Explore as a separate static SPA

NextOps documentation browsing is a **Documentation Explorer** (文件探索中心) — a Vite + Svelte static SPA under `docs/explore-app/`, not a session-authenticated route inside the SvelteKit operator dashboard. Keeping explore off the Cluster Operator critical path avoids coupling doc UX to dashboard auth/deploy, while still reflecting codebase change via a build-time **code surface** inventory (UI `+page.svelte` routes + `api/**/+server.ts`) and a doc↔code graph. Drift (undocumented or stale surfaces) is **soft**: always visible in-app, never blocks `docs:explore` / merge. Curated Markdown is read in-app (dual mode with “Open source”); ADRs/design/plans stay outbound; `docs/features/` stays embedded for v1. Publish host is TBD (local-first + CI artifacts); do not commit `dist`. Rejected: in-dashboard `/docs`, deep GitNexus symbol graphs, and hard-fail CI on doc drift for v1.
