NextOps 功能導覽

Cluster Operator 面向頁面的視覺導覽 — 術語對照見 CONTEXT.md

導覽模型

側邊欄僅含日常監控三項：全球矩陣大盤、智能日誌流、告警中心。 頂部列提供管理配置（/admin）與告警徽章。

/ai 與 /admin/diagnosis 為刻意不在側邊欄的 直接 URL 路由（Direct URL Route）——功能完整，但需直接輸入 URL、書籤 / runbook 連結， 或從情境入口進入（例如大盤診斷橫幅）。此為產品設計決策，非遺漏。

Dify Integrator： Dify Chatflow Phase I 配置指南 （開始 / LLM / 直接回覆節點與 Tool Endpoint 參數；亦可在 Documentation Explorer 選「Dify Chatflow」）。

導覽模型 登入 全球矩陣大盤 Site Detail 智能日誌流 告警中心 AI 診斷 SRE 管理配置 上游診斷

登入 /login

Session 驗證 Cluster Operator 的進入點

操作者僅輸入管理員密碼（UI 固定以 admin 使用者名稱呼叫 API； 伺服器驗證 NEXTOPS_ADMIN_USER / NEXTOPS_ADMIN_PASS，預設見 .env.example）。 成功後設定 session Cookie，瀏覽器導向全球矩陣大盤（/）。

  • 置中登入卡片（login/+layout.svelte 樣式；繼承 root layout 的 app shell）
  • 登出：側邊欄底部 登出 → POST /api/auth/logout

全球矩陣大盤 /

Prometheus MySQL 頁面標題：混合資源 調度指揮中心

跨 Site 的指揮視圖，呈現全局 KPI 與 Site 卡片網格。 每張卡片彙總 K8s 與節點資源使用率、Pod 就緒數與告警數量。 點擊卡片可進入 Site Detail。

  • KPI 指標列 — 服務響應整體健康度、服務響應平均延遲、流水線成功率、流水線超時率
  • 告警趨勢圖 — 近期 firing 告警的時間分布（告警趨勢 24H）
  • Site 卡片 — 各 Site 的 K8S / 節點 CPU、記憶體、磁碟，節點數量，連結至 /sites/[title]
  • 自動刷新 — 30 秒倒數計時，可手動刷新
  • 上游錯誤狀態 — 無內嵌演示資料；上游不可用時 KPI / Site 卡片顯示紅色邊框、錯誤圖示與上游錯誤訊息；Site 清單失敗時顯示錯誤面板。告警趨勢圖為錯誤狀態或空（無種入告警）。本地開發須連上真實上游，否則會看到錯誤狀態。

API： GET /api/sites、 GET /api/sites/:id/overview、 GET /api/prometheus/global-metrics、 GET /api/pipeline-metrics

側邊欄：全球矩陣大盤

Site Detail /sites/[siteId]

Prometheus Site 設定 範例：/sites/龍華-生產

單一區域叢集的營運鑽取頁面。顯示即時 Prometheus 指標、節點狀態網格、 告警摘要，以及 AI 診斷工具使用的 Site 中繼資料（ES 索引、指標名稱等）。

  • 指標卡片 — Kubernetes (K8S) 與節點的 CPU / 記憶體 / 磁碟分組
  • 節點狀態網格 — 線上 / 總節點數、Pod 就緒數
  • 告警摘要 — critical / warning 數量
  • PromQL 設定面板 — 覆寫查詢模板（localStorage）
  • 輪詢 — 可設定刷新間隔（預設 30 秒）

API： GET /api/sites/:siteId/overview、 GET /api/sites/:siteId/describe

智能日誌流 /logs

Elasticsearch SSE 頁面標題：智能日誌流

從中央 Elasticsearch 近即時串流叢集日誌。必須先選 Site 並設定 Index Watchlist，瀏覽器才會以 SSE 連到 /api/logs/stream。表格上方的框選日誌分析可勾選最多 20 筆已載入列，按「送出分析」走 /api/ai/query，結果顯示在浮動日誌分析視窗（不是 OPSGPT 聊天列）。

  • Site + Watchlist — 單一站點、單一 active index family
  • Document Filter — 從欄位表 / JSON Tree 點值過濾
  • Log Category — 可編輯規則與 ES 命中數
  • 時間／關鍵字 — 5m–24h 與 query_string
  • 框選日誌分析 — 列左側核取方塊 → 送出分析 → Analysis Window
  • 自動捲動 — 跟隨新日誌條目
  • 連線狀態 — connecting / connected / reconnecting / error

側邊欄：智能日誌流

告警中心 /alerts

Alertmanager SSE 頁面標題：告警中心

從 Alertmanager Webhook 匯入的即時告警 feed。告警依 fingerprint 去重， 透過 SSE 廣播至已連線瀏覽器。未讀的 firing 告警顯示於側邊欄與頂部徽章。

  • 篩選 — Site、嚴重度、狀態、搜尋、時間範圍
  • 摘要列 — 總數、firing、critical、warning、info 計數
  • 確認（Acknowledge） — 標記已讀（POST /api/alerts/ack）
  • 即時更新 — SSE 快照 + 增量事件
  • 空狀態至 Webhook 就緒 — 程序啟動時不種入演示告警；生產須設定 Alertmanager Webhook，告警依 fingerprint 去重與更新

側邊欄：告警中心（含未讀徽章）

AI 診斷 /ai

Dify 頁面標題：運維助手

左右分欄：左側為站點健康簡報（Site Health Brief），右側為 OPSGPT 對話。 問題經 POST /api/ai/query 送至編排層（預設 LangGraph），以 SSE 串流回應。

  • Site 選擇器 — 從 GET /api/sites 載入；未綁定顯示全站 overview
  • Site Health Brief — 綁定後為資源健康 + firing 告警；「產生報告」才寫入 Diagnosis Answer
  • ChatPanel — 自然語言問答與串流輸出（與產生報告同一對話）
  • Tool Endpoint — 編排層分析期間伺服器端查詢 Prometheus / 告警

導覽：直接 URL 路由 — 刻意不在側邊欄。 請直接開啟 /ai 或使用書籤 / runbook 連結（見上方導覽模型）。

SRE 管理配置 /admin

環境變數顯示 localStorage 頁面標題：SRE 管理配置

唯讀顯示預設連線設定（Elasticsearch、Prometheus、Proxy、Dify API）。 操作者可在瀏覽器端覆寫；覆寫值以 nextops-config 持久化於 localStorage。

  • 服務卡片 — LOGGING — ElasticSearch、RESOURCE — Prometheus、PROXY、AI AGENTS — DiFy API
  • 字型大小設定 — 無障礙用的 CSS 變數覆寫
  • PromQL 設定面板 — 與 Site Detail 共用

頂部導覽：管理配置（齒輪圖示）

上游診斷 /admin/diagnosis

記憶體註冊表 頁面標題：系統健康診斷與異常註冊表

當 NextOps 無法連線至 Elasticsearch、Prometheus 或 MySQL 時， 向 Cluster Operator 展示近期上游失敗記錄。錯誤於 API 代理呼叫期間自動登記， 可批次清除。

  • 錯誤清單 — 服務名稱、訊息、時間戳、active / resolved 狀態
  • 可展開詳情 — 每筆記錄的完整錯誤上下文
  • 清除所有錯誤 — POST /api/diagnosis，action: clear

導覽：直接 URL 路由 — 刻意不在側邊欄。 主要入口為大盤紅色橫幅「系統診斷警報」→ 查看診斷詳情； 亦可直接開啟 /admin/diagnosis（見上方導覽模型）。
