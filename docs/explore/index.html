功能導覽

導覽模型：側邊欄僅含日常監控三項（大盤、日誌、告警）。 頂部列提供管理配置與告警徽章。/ai 與 /admin/diagnosis 為 Direct URL Route — 刻意不在側邊欄，需直接 URL 或情境入口進入。

詞彙與規劃

領域語言、文件路線圖與完整性審查

以下為 CONTEXT.md 核心詞彙摘要。 完整定義、應避免用語與英文對照請見根目錄詞彙表。

Site（區域叢集）
具 cluster_tag 的實體部署叢集，推送資料到中央 ES + Prometheus
Cluster Operator
使用 NextOps 監控與診斷叢集健康的主要角色（SRE / DevOps）
Global Matrix Dashboard
登陸頁 / — 跨 Site KPI、Pipeline 健康與 Site 卡片網格
Smart Logging
/logs — 從 ES 近即時串流叢集日誌，可設定篩選條件
Alert Center
/alerts — Alertmanager webhook 餵入，SSE 推播至瀏覽器
AI Diagnosis
LLM 驅動根因分析；Dify 編排 Tool Endpoint 收集資料後回傳自然語言解釋
Tool Endpoint
Dify Agent 在診斷時呼叫的 HTTP 端點（如 get_site_overview）
Direct URL Route
刻意不在側邊欄的路由（/ai、/admin/diagnosis），需直接 URL 或情境入口
Upstream Error State
上游不可達時 UI 顯示紅色邊框、錯誤圖示與錯誤訊息 — 無內嵌占位資料；操作者須修復上游連線
Upstream Diagnosis
/admin/diagnosis — API 代理呼叫 ES / Prometheus / MySQL 失敗的登錄表
